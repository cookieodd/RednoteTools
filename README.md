# RednoteTools

小红书 9.52 去水印保存。越狱装 deb，或巨魔注入 dylib。

## 功能
- 笔记：图片 / 视频 / Live Photo，单张或批量
- 图集表情包：当前 Live Photo 转为循环 GIF
- 评论区：图片 / Live Photo / 表情包
- 无水印、无版权动画
